📡Local ADS-Bdump1090 / readsb▸

Local receiver feed (dump1090-fa, readsb, or tar1090). Merges with FR24/adsb.fi; local positions win on overlap. Leave off if nothing is listening — connection refused will spam the logs.

📡Route Sourcesorder & fallback▸

Comma-separated: airlabs, flightaware, opensky — tried in this order, first match per field wins, gaps filled by the next. Omit an entry to disable it entirely. Example for a fully free/open-source lookup with no paid API ever called: opensky. Leave blank for the default order (airlabs,flightaware,opensky).

🗺Position Sourcesextended tracking map▸

Fallback order for the live-centered map (Radar > Track > swipe to live map). First source that has a fresh position for the tracked aircraft wins. Drag to reorder; a source with no key/URL configured is skipped automatically even if left in the list.

⚠Alertsflight #, type, registration▸

Highlight many aircraft on the local radar when they enter range — not a worldwide follow (use Tracking for that). Enter ICAO flight numbers (UAL1083) and/or registrations / tail numbers (N2136U, D-AIML), comma-separated. Clear and Save to remove.

Alert on every aircraft of a given type on local radar. Use ICAO type codes (B738, A337) or designations (A330-743), comma-separated. Clear and Save to remove.

✈Trackingone flight # or tail worldwide▸

Follow one aircraft worldwide on the Tracked screen (route, ETA, pin) — even outside radar range. Enter an ICAO flight number (UAL1083) or a registration / tail number (N2136U, CS-TPQ). For many flights or types on local radar only, use Alerts instead.

☁Weatherunits▸

Clears the local rate-limit backoff and asks the display to call Tomorrow.io once. Current weather/wind also refresh automatically at :01 and :31; forecast with the :01 slot. Use sparingly (free tier ≈ 25 requests/hour).

♫ATC AudioLiveATC▸

Manual LiveATC stream to the Pi’s USB or Bluetooth speaker via mpv (sudo apt install mpv). Pair a Bluetooth speaker in the card below. Airport lists every large/medium field in radar range. Channel loads local seed/index immediately, then auto-fetches the full LiveATC feed list in the background (Cloudflare-bypass search). Enable ATC audio to start playback; disable to stop. Changing airport or moving the map while ATC is enabled selects that area’s Tower and keeps playing. Playback resumes after reboot/app restart when it was left enabled. Quiet hours block auto-resume after reboot; turning ATC on again overrides quiet hours until you disable it.

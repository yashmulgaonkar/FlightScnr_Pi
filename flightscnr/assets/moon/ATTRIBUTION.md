# Moon image attribution

`moon_full.jpg` is a full-moon frame from NASA's Scientific Visualization
Studio "Moon Phase and Libration, 2026" (visualization 5587, frame 0060),
rendered from Lunar Reconnaissance Orbiter data.

- Source: https://svs.gsfc.nasa.gov/5587/
- Credit: NASA's Scientific Visualization Studio / Ernie Wright
- License: NASA imagery is not copyrighted (public domain); credit requested.

`ATTRIBUTION.md`).
